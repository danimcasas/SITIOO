SITIOO · WINDOWS 11 X64 · 0.3.0-beta.1

Manual de la aplicación

Crea WordPress en tu ordenador y prepara sus copias para migrarlo.

Esta es una beta. Consulta el informe de pruebas de la entrega antes de utilizarla con un proyecto importante. El instalador no tiene firma digital de Windows.

Instalar · Crear un sitio · Accesos · Copias y migración · Conservar y actualizar · Limitaciones

1. Instalar SITIOO

Necesitas Windows 11 de 64 bits, una cuenta normal de Windows, un disco local con permisos de escritura y espacio libre para la aplicación y tus proyectos. Reserva al menos 3 GB para empezar; las imágenes, los plugins y las copias aumentan el espacio necesario. Para trabajar con comodidad se recomiendan 8 GB de memoria. Estas cifras son orientativas, no una certificación en un PC mínimo.

  1. Obtén SITIOO-0.3.0-beta.1-windows-x64-setup.exe de una entrega de confianza. El archivo SHA256SUMS.txt permite comprobar que la descarga no ha cambiado.
  2. Abre el instalador, lee la licencia y elige una carpeta para la aplicación. Se instala para tu cuenta, sin instalar servicios generales.
  3. Finaliza el asistente y abre SITIOO desde el menú Inicio.

PHP, MariaDB, WordPress y los componentes de escritorio vienen incluidos. No necesitas instalar Node.js, PHP ni MariaDB por separado. La primera apertura puede tardar mientras Windows comprueba los archivos. Si Windows bloquea el instalador, conserva el mensaje y revisa el origen y la suma del archivo; no desactives las protecciones.

2. Crear y utilizar un sitio

  1. Pulsa Crear proyecto y escribe un nombre.
  2. Elige el usuario administrador: entre 3 y 32 letras, números, puntos o guiones.
  3. Escribe una contraseña de entre 12 y 128 caracteres. Evita saltos de línea.
  4. Marca Guardar acceso en este equipo si quieres que SITIOO recuerde el usuario y la contraseña de forma cifrada.
  5. Pulsa Crear mi proyecto y espera a que termine el avance. Se instala WordPress y se activa SITIOO Migration.
  6. Pulsa Administrar WordPress. En el navegador, entra con los datos que acabas de crear.

Cada proyecto tiene sus propios archivos, base de datos y dirección local. 127.0.0.1 significa «este ordenador»; el número que aparece después identifica el sitio. Abrir web muestra la portada y Administrar WordPress abre wp-admin, su zona de administración.

Las páginas y entradas se editan dentro de WordPress. Utiliza temas y plugins de confianza. SITIOO no configura un hosting ni publica el sitio en Internet. El correo estándar de WordPress está bloqueado en los proyectos locales de esta beta; no pruebes envíos reales ni cobros.

3. Iniciar, detener y cerrar

En Mis proyectos, pulsa Iniciar proyecto para volver a abrir un sitio detenido. Pulsa Detener cuando termines. Al cerrar SITIOO se cierran sus componentes y se conservan los archivos. Al volver a abrir la aplicación, inicia los proyectos que quieras utilizar.

Espera a que termine una creación, copia, duplicación, recuperación, importación o actualización antes de cerrar. Si aparece un aviso de puerto ocupado, deja abierta la aplicación ajena y vuelve a intentarlo cuando ese puerto quede libre. SITIOO no cierra procesos de otras aplicaciones. Una instalación incompleta queda marcada para revisión y conserva sus archivos; la reparación automática de una creación fallida está pendiente.

4. Conservar y recuperar los accesos

Abre Acceso a WordPress en la tarjeta del proyecto. Puedes guardar o actualizar sus datos, copiar el usuario o la contraseña, mostrarla durante un momento y quitar la copia guardada. Mostrarla se desactiva al cambiar de ventana y, como máximo, tras 30 segundos.

Este apartado recuerda los datos que introduces. Si cambias la contraseña dentro de WordPress, actualiza también la copia guardada en SITIOO. Quitarla requiere confirmación y conserva la cuenta de WordPress.

Windows protege los accesos y las claves del motor con tu cuenta. Si el cifrado falla, SITIOO muestra un error y no guarda una alternativa sin cifrar. Conserva la carpeta de datos completa, incluidos los archivos de configuración del perfil: copiar solo los sitios y los archivos de acceso a otro perfil puede impedir descifrarlos. La recuperación necesita las claves protegidas del perfil y de la misma cuenta de Windows. Para llevar el contenido a otro equipo, utiliza una exportación y conserva el administrador del destino.

La beta no incorpora un botón para restablecer una contraseña olvidada. Si no la guardaste y no puedes entrar, conserva el proyecto y solicita una recuperación técnica. La recuperación por correo no está disponible en estos sitios locales.

5. Crear una copia y exportarla

  1. En la tarjeta del sitio, abre Copias y migración.
  2. Añade una nota opcional y pulsa Crear nueva copia. Se genera una versión numerada; evita editar WordPress durante el proceso.
  3. Pulsa Exportar para producción junto a esa versión y elige una carpeta.
  4. Conserva juntos sitioo-manifest.json, todos los ZIP de datos, el ZIP del plugin y las instrucciones.

La copia incluye las tablas de WordPress y los archivos de temas, plugins e imágenes. Excluye el núcleo de WordPress, wp-config.php, las contraseñas que recuerda SITIOO, las claves privadas del motor, los plugins obligatorios del servidor, cachés y ciertos ajustes especiales. Las cuentas de WordPress y sus datos forman parte de su base de datos. Los paquetes no están cifrados: guárdalos como datos privados y no los publiques.

SITIOO crea estas copias. El plugin SITIOO Migration importa los paquetes y conserva información para recuperar una migración. El plugin no crea copias autónomas del hosting.

6. Duplicar, recuperar e importar en SITIOO

Estas tres operaciones crean un proyecto nuevo y conservan el original. Cada destino tiene su propia base de datos, dirección local y claves de Windows. El nombre identifica el proyecto en SITIOO; el título del sitio se conserva dentro de WordPress.

Duplicar el estado actual

  1. En la tarjeta del sitio pulsa Duplicar proyecto.
  2. Elige un nombre y el usuario y contraseña del nuevo proyecto. Puedes guardar ese acceso cifrado.
  3. Confirma que confías en el contenido y pulsa Crear proyecto desde esta copia.

SITIOO guarda una copia numerada del estado actual. Pausa brevemente la web mientras la crea y después recupera el estado de inicio o parada que tenía. Evita editar el sitio durante ese paso.

Recuperar una versión anterior

  1. Abre Copias y migración y localiza la fecha y nota que necesitas.
  2. Pulsa Recuperar como nuevo proyecto junto a esa copia.
  3. Elige el nombre y el acceso del nuevo sitio y confirma la operación.

El proyecto recuperado tendrá los datos de esa copia. El sitio actual y todas las copias del historial se conservan.

Importar una exportación

  1. Conserva juntos sitioo-manifest.json y todos los ZIP de datos, en una carpeta de tu equipo. Si recibiste un ZIP que contiene esa carpeta, extráelo primero.
  2. Pulsa Importar copia y selecciona sitioo-manifest.json. Los ZIP de datos se mantienen cerrados.
  3. Revisa el número de copia, la versión de WordPress y el tamaño. Elige un nombre y un acceso nuevo y confirma.

SITIOO comprueba que estén todos los paquetes y que no hayan cambiado. Solo admite el formato 1 de SITIOO y una versión de WordPress igual o anterior a la incluida en la aplicación. Un ZIP de otro programa o una carpeta de WordPress sin exportar no se pueden importar con este botón.

Comprobar el resultado

El nuevo proyecto queda detenido. Pulsa Iniciar proyecto y después Administrar WordPress; usa el acceso que acabas de elegir. SITIOO Migration está activo. Los demás plugins se conservan inactivos para que revises sus versiones, ajustes y servicios externos antes de activarlos. Los temas y archivos compatibles se conservan, y los enlaces se adaptan a la dirección local nueva.

Si ya existe un usuario con el mismo nombre en la copia, el destino recibe la contraseña nueva que has elegido. Las otras cuentas incluidas en la base de datos se conservan. El acceso del proyecto original permanece igual.

Si la operación se interrumpe, el origen y la copia se conservan. El destino incompleto queda marcado para revisión y sus archivos se guardan. Repite la operación desde la copia original para crear otro destino. La continuación automática de una importación interrumpida en la aplicación está pendiente. La recuperación de migraciones desde el plugin del hosting tiene su propio procedimiento, explicado en su manual.

Importar en un hosting o cambiar de dominio

Prepara un WordPress compatible en el hosting, conserva una copia independiente de ese destino y utiliza Herramientas → SITIOO Migration. El plugin adapta los enlaces al dominio configurado allí. Sigue el manual del plugin para subir, comprobar, confirmar, reanudar o recuperar la migración. SITIOO no configura DNS, hosting ni certificados HTTPS.

7. Plugin en proyectos existentes

En la tarjeta del proyecto pulsa SITIOO Migration. La aplicación ofrece instalarlo, activarlo o actualizar una versión conocida. La operación requiere confirmación, pausa el sitio y conserva su contenido. Una versión anterior reconocida se guarda fuera de la carpeta pública antes de sustituirla.

Si encuentra una versión desconocida o archivos modificados, detiene la sustitución y explica el motivo. No borres ese plugin para forzar el cambio: revisa primero su compatibilidad. Puedes guardar un ZIP independiente desde Copias y migración → Guardar plugin SITIOO Migration. Su instalación no depende de GitHub.

8. Actualizar, desinstalar y conservar los sitios

La actualización de SITIOO es manual. Cierra la aplicación, conserva una copia de los datos y ejecuta el nuevo instalador para la misma cuenta de Windows. Los proyectos se guardan aparte de la aplicación. La beta no incorpora actualización automática de SITIOO ni del motor.

La ubicación habitual de datos es %APPDATA%\SITIOO. Desde Ayuda → Abrir carpeta de datos puedes localizarla sin escribir rutas. Cierra SITIOO antes de copiar esa carpeta completa: incluye proyectos, su registro, accesos cifrados y copias. No copies una base de datos mientras está funcionando.

Para desinstalar, usa Configuración de Windows → Aplicaciones → Aplicaciones instaladas → SITIOO → Desinstalar, o el desinstalador incluido. El proceso conserva los sitios, las copias y los accesos por defecto. Vuelve a instalar con la misma cuenta para recuperarlos. No elimines manualmente la carpeta de datos si quieres conservarlos.

9. Limitaciones de esta beta

  • Orientada a WordPress individual local. No incluye creación específica de tiendas WooCommerce, Multisite ni servidores públicos.
  • Sin firma digital, actualización automática ni comprobación en un Windows limpio dentro de este encargo.
  • Las pruebas se han hecho en un PC Windows real. Reiniciar la aplicación y reiniciar Windows son pruebas distintas; consulta cuáles constan como superadas.
  • El formato de migración sigue siendo el formato 1. La validación del formato no sustituye una prueba física en Mac.
  • Las copias de preparación y los archivos de intentos fallidos se conservan y ocupan espacio. No hay limpieza automática.
  • La importación conserva el WordPress y la configuración del destino. Reglas del servidor, correo, servicios externos, licencias de plugins y ajustes excluidos requieren revisión.
  • Los nombres incompatibles con Windows, enlaces simbólicos y estructuras especiales de base de datos se rechazan con un aviso.

Consulta también el glosario y las preguntas frecuentes y el informe de pruebas de esta entrega.
