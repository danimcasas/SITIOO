# Continuar la landing de SITIOO con Claude o Codex

Actualiza la landing existente de SITIOO conservando su identidad, sus enlaces válidos y la información del curso que ya esté publicada. Antes de publicar, prepara una vista previa para revisar los cambios. Lee README.md, CHANGELOG.md, MACOS.md, PRUEBAS-MAC-0.3.md y los tres manuales HTML de esta carpeta.

## Estado que debe reflejar

- Mac: 0.3.0-beta.2, Apple Silicon, macOS 26 o posterior. DMG con motor incluido, sin Developer ID ni notarización Apple.
- Windows publicado anteriormente: 0.3.0-beta.1, Windows 11 x64, instalador guiado sin firma digital. Las nuevas pruebas Mac no sustituyen pruebas Windows.
- SITIOO Migration 0.3.0-beta.2: descarga ZIP independiente para instalar desde WordPress. No exige descargar el código ni acceder a GitHub. La aplicación lo instala y activa en nuevos proyectos y permite actualizar versiones reconocidas en existentes.
- Proyectos independientes, acceso a wp-admin, accesos guardados con cifrado del sistema, copias completas numeradas, duplicación, recuperación como proyecto nuevo e importación local.
- SITIOO crea copias; el plugin las importa, adapta el dominio y permite recuperar la migración. No anunciar copias autónomas del hosting, compatibilidad con cualquier hosting, WooCommerce automatizado ni tamaños máximos como si se hubieran probado.

## Descargas y ayuda

El ZIP del plugin puede alojarse directamente junto a los archivos de la landing o en su biblioteca de medios. Debe ser descargable sin visitar GitHub. Mantén juntos los manuales HTML y manual.css para conservar su formato y enlaces. Puedes integrar su contenido en la web, incluyendo el glosario y las preguntas frecuentes.

Publica botones separados de Mac, Windows y plugin, con versión y requisitos visibles, más enlaces a los manuales y notas de prueba. Usa los archivos y sumas de la entrega real. Nunca inventes una URL de descarga ni sustituyas un enlace verificado antes de que el archivo nuevo esté disponible. Mantén las versiones anteriores accesibles.

En Mac, Importar copia selecciona la carpeta exportada que contiene el índice y todos los ZIP; en Windows se selecciona sitioo-manifest.json. Explica este paso con palabras sencillas.
