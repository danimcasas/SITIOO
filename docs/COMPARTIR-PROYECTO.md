# Trabajar con el repositorio de SITIOO

El repositorio público de código es [danimcasas/SITIOO](https://github.com/danimcasas/SITIOO). La [página oficial](https://danimcasas.com/sitioo-wordpress-local/) enlaza los instaladores, el plugin y las guías de descarga. No usar una carpeta sincronizada para compartir una base de datos activa entre ordenadores.

La copia limpia incluye app, plugin, recursos, scripts, tests, documentación y licencias. Excluye .local, node_modules, bases de datos, accesos guardados, certificados y binarios del motor. El DMG se entrega separado. No subir todo el directorio de trabajo original.

## GitHub

El repositorio contiene los archivos de código y documentación descomprimidos. Los instaladores y motores redistribuidos se mantienen fuera del historial de código. La publicación inicial parte de una copia revisada de beta.2; el historial local anterior no se publica. Configurar una identidad de commit que no exponga un correo privado. No guardar tokens en scripts o documentos.

## Codex y Claude

Para trabajar localmente, obtener el código y abrir su carpeta. Seguir [WINDOWS-11.md](WINDOWS-11.md), [MIGRACION.md](MIGRACION.md) y [ACCESOS-LOCALES.md](ACCESOS-LOCALES.md), además del informe de pruebas. Las instrucciones internas de trabajo quedan fuera del repositorio público.

Para un agente en la nube, conectar GitHub desde la cuenta del propietario y conceder acceso solo al repositorio SITIOO. Una carpeta de Drive privada no concede acceso automáticamente a Claude o Codex. No existe una dirección genérica de Claude o Codex a la que debamos invitar. Si se comparte con una persona, confirmar antes la cuenta exacta y el nivel de acceso.

Mantener Windows y la landing en ramas o carpetas separadas. La landing puede trabajar con el brief y los recursos visuales sin recibir ninguna web de clientes ni credenciales.
