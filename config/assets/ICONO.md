# Icono de SITIOO

Creado con la herramienta integrada image_gen. No se utilizó API ni CLI externa.

Archivos: sitioo.png (original con transparencia) y sitioo.icns (conversión al contenedor multirresolución nativo de macOS). El fondo dmg-background.png se compone mediante el script de diseño local scripts/prepare-brand-assets.py.

Prompt utilizado:

Create a single polished macOS application icon for SITIOO, a friendly desktop app for learning WordPress. Square canvas, genuine transparent background outside the icon. A large softly rounded purple square, rich vivid purple #6D4AFF with extremely subtle premium depth, containing one bold perfectly readable white uppercase S and a small lime green circular dot at its lower right. Minimal, elegant, crisp, friendly. The S and dot are the only glyphs; no additional text, no WordPress logo, no computer or disk depiction, no borders or decorative objects. Icon fills about 86% of canvas with comfortable equal transparent margins. Straight-on view, balanced optical proportions, readable at 32 pixels. Deliver a production app icon, not a mockup.
