VERSIONES DE TU PROYECTO

Copias y migración

Crea una copia completa y numerada. Puedes recuperarla como otro proyecto local o exportarla para llevar tu web a un hosting.

La web local se pausa mientras se crea la copia. Evita editarla durante ese tiempo. Los ZIP contienen datos privados: guárdalos en un lugar seguro.

Cómo pasarla al hosting

  1. Exporta una copia de la lista.
  2. Instala WordPress en el hosting con la misma versión o una posterior.
  3. Instala el ZIP sitioo-migration desde Plugins → Añadir plugin.
  4. En Herramientas → SITIOO Migration, sube el manifiesto y los ZIP de datos.
  5. Comprueba el dominio de destino y confirma la importación.

Se conserva el administrador del hosting. Los plugins importados quedan inactivos hasta que revises su compatibilidad. Esta beta no admite Multisite ni sustituye la configuración del servidor.

Un lugar para aprender

Para conservar una copia completa del equipo, cierra SITIOO y copia esta carpeta. Los accesos cifrados necesitan la misma cuenta de Windows o macOS.

Crea un proyecto y pulsa «Administrar WordPress» para empezar.

Tu web solo estará disponible en este ordenador. Al cerrar SITIOO se detienen sus servidores; tus archivos se conservan.

Instala temas y plugins únicamente de fuentes confiables. Las funciones que necesitan una dirección pública pueden no funcionar en local.

Para probar cambios en otra web, pulsa «Duplicar proyecto». En «Copias y migración» puedes recuperar una versión anterior como otro proyecto. «Importar copia» permite seleccionar el archivo sitioo-manifest.json de una exportación, junto a todos sus ZIP.

Estas operaciones crean proyectos independientes y conservan el origen. Elige un nuevo acceso y revisa los plugins importados antes de activarlos. Si una importación falla, conserva sus archivos y repite desde la copia original.

Esta beta se centra en WordPress. WooCommerce y actualizaciones automáticas todavía no están disponibles.
